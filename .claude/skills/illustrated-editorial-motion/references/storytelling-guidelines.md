# Storytelling guidelines

## From script to scenes
1. **Understand** each sentence: what changes for the viewer (a number, a contrast, a reason)?
2. **Main message** of the whole piece in one line.
3. **Visual metaphor:** find the object that *is* the idea (price tag = value, scale = decision, blocks = cost vs price, door/storefront = business, coin = profit). Literal only when the object is the topic.
4. **Composition** from the pattern list; alternate patterns (no two adjacent scenes with the same composition).
5. **Assets:** hero + 1–3 supports + label; reuse before creating.
6. **Animation / camera / transition** per the language docs.
7. **Duration:** ≈ 2.0–3.5 s per scene; derive from VO when available (sentence length + 0.3 s lead + 0.25 s gap) or from ≈ 150 words/minute. Number-heavy scenes get +0.5 s.
8. **Continuity:** persistent hero (e.g. the bowl) across scenes, same background family, consistent price-tag position language.

## Structure that worked in the reference (≈80 s) — reuse as a skeleton
Hook (surprising contrast) → question → decompose (item by item) → fixed costs → break-even → result number → comparison/battle → question to audience → CTA.
For 15–30 s: Hook → 2–3 build scenes → number reveal → summary.

## Composition patterns
isolated object · top-down · illustrated environment · character-centered · infographic · comparison · sequential assembly · before/after · visual metaphor.

## Do / don't
- Do reveal numbers one at a time; do pair every number with its object.
- Do end each scene on a held frame.
- Don't stack more than one concept per scene; don't use text as the only content; don't repeat an object in the same position scene after scene unless it is the continuity hero.
